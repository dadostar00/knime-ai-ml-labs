# Lab 1: NYC Taxi Price Prediction (Regression)

## Traccia del Laboratorio
In questo esercizio l'obiettivo è predire l'importo totale (`total_amount`) per le corse dei taxi a New York utilizzando un modello di regressione, valutando l'impatto di feature quali data/ora, distanza, durata e velocità media.

**Passaggi principali richiesti:**
1. Importazione del dataset `yellow_tripdata_2015-09` e pulizia tramite il componente fornito.
2. Partizionamento dei dati (almeno 70% nel Train Set estratto casualmente).
3. Addestramento del *Regression Learner* con target `total_amount`.
4. Valutazione sul Test Set tramite *Regression Predictor* e *Numeric Scorer*.
5. Visualizzazione grafica delle predizioni sovrapposte ai dati reali.
